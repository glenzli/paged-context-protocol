# Deprecated Protocol Generations

This directory preserves superseded PCP specifications as historical design
records. They remain available because protocol evolution is part of the
project's technical history, but they are not current implementation guidance.

本目录保存已经停止演进的 PCP 协议版本。它们作为设计史继续保留，但不再代表当前
实现规范。

## Archived Generations

- [`v0.3.0-alpha`](v0.3.0-alpha/README.md): the processor-oriented runtime
  protocol based on fixed routing, recursive zoom states, XML synthesis, and a
  separate PCP-native Memory profile.

The current draft is maintained at the repository root:

- [PROTOCOL-en.md](../PROTOCOL-en.md)
